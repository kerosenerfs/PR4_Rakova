Контрольные вопросы 

1. Когда вызывается автозагрузчик и что если файл не найден?
    PHP вызывает автозагрузчик при первом обращении к неизвестному классу (new, instanceof, статический вызов). Если ни один автозагрузчик не нашёл файл – фатальная ошибка Class "..." not found.

2. Преимущество spl_autoload_register() перед __autoload()
    Можно зарегистрировать несколько автозагрузчиков (а не один), их можно отключать. __autoload() удалена из PHP 8.0.

3. Абстрактный класс vs интерфейс
    Абстрактный класс – содержит реализацию, свойства, состояние; наследование только одно. 
    Интерфейс – только сигнатуры методов и константы; класс может реализовывать несколько интерфейсов. Выбирают абстрактный класс для родственных сущностей, интерфейс – для «контракта поведения».

4. Объект абстрактного класса и абстрактное свойство
    Создать объект абстрактного класса нельзя (ошибка при new). Объявить абстрактное свойство нельзя – абстрактными могут быть только методы.

5. static-свойство vs обычное
Обычное – у каждого объекта своё. static – одно на весь класс, общее для всех экземпляров. Внутри класса обращение через self::$prop, снаружи – через ClassName::$prop.

6. Модификатор readonly
    Запрещает изменять свойство после первой инициализации (обычно в конструкторе). Ограничения: только типизированные свойства, нельзя static, присвоить значение можно один раз.
